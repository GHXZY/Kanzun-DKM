## 📌 Tentang Kanzun

**Kanzun** (diambil dari bahasa Arab: *Kanz* / كنز yang bermakna khazanah atau perbendaharaan berharga) adalah aplikasi manajemen perbendaharaan dan akuntabilitas keuangan masjid berbasis Android. 

Kanzun dirancang khusus untuk memecahkan kendala klasik pengelolaan dana umat yang selama ini kerap bertumpu pada pencatatan manual buku kas atau *spreadsheet* umum. Kanzun bukan sekadar buku kas digital pencatat keluar-masuk uang, melainkan **ekosistem perbendaharaan utuh** yang mengintegrasikan alokasi dana khusus, anggaran (RAPBM), pengelolaan aset masjid, penyaluran zakat, serta pelaporan formal berstandar audit yang siap dipertanggungjawabkan kepada Ketua DKM, pembina, maupun seluruh jamaah.

> *"Membantu masjid mengelola amanah keuangan secara tertib, transparan, dan mudah dipertanggungjawabkan."*

## 🌟 Keunggulan Utama

Mengapa Kanzun berbeda dengan aplikasi pencatatan keuangan biasa?

### 1. 🏛️ Konsep Dana Bertingkat (*Fund Allocation & Restricted Funds*)
Saldo total masjid yang besar tidak otomatis berarti seluruh uang tersebut bebas digunakan. Kanzun memisahkan konsep:
* **Akun Penyimpanan:** Rekening Bank vs. Kas Tunai (*Cash on Hand*).
* **Alokasi Dana (*Fund*):** Dana Operasional, Dana Pembangunan & Renovasi, Dana Pendidikan, Dana Sosial, dan Wakaf.
* **Kategori Transaksi:** Operasional listrik/air, honor marbot/asatidz, pemeliharaan fisik, konsumsi takjil, dsb.

### 2. 📊 RAPBM & Analisis Deviasi (*Budget vs. Actual*)
Mendukung perencanaan keuangan formal masjid per tahun anggaran:
* Penyusunan pagu anggaran pendapatan dan belanja (RAPBM).
* Pemantauan realisasi anggaran secara *real-time* (*Under Budget*, *On Budget*, *Over Budget*).
* Peringatan dini (*early warning alert*) saat pos pengeluaran mendekati atau melampaui batas toleransi anggaran.

### 3. ⚖️ Rekonsiliasi Kas & Transfer Antar-Kas Transparan
* **Transfer Kas Bebas Distorsi:** Memindahkan saldo kas fisik ke rekening bank (atau sebaliknya) tanpa tercatat keliru sebagai beban pengeluaran atau pemasukan baru.
* **Fitur Rekonsiliasi Berkala:** Membandingkan saldo catatan sistem dengan uang fisik riil di brankas/kotak infak, lengkap dengan dokumentasi berita acara selisih kas.

### 4. 🌙 Modul Zakat Khusus Asnaf
Mengakomodasi syariat pemisahan dana zakat dari kas operasional:
* Pencatatan penerimaan zakat (Zakat Fitrah, Zakat Maal, Fidyah).
* Distribusi tepat sasaran berbasis 8 Asnaf (Fakir, Miskin, Amil, Mualaf, Riqab, Gharimin, Fisabilillah, Ibnu Sabil).
* Pantauan saldo dana zakat yang wajib disalurkan secara terpisah.

### 5. 🎯 Manajemen Target Dana & Donasi (*Fundraising Campaigns*)
* Melacak progres penggalangan dana program strategis (contoh: Renovasi Tempat Wudhu, Pengadaan Karpet, Sound System).
* Dilengkapi visualisasi persentase capaian target nominal, durasi tenggat waktu, dan riwayat donatur.

### 6. 📦 Inventarisasi & Manajemen Aset Masjid
* Mendata seluruh aset bergerak dan tidak bergerak milik masjid (Tanah Wakaf, Bangunan, Kendaraan Operasional, Perangkat Audio/Visual, AC, Inventaris Kantor).
* Pencatatan nilai perolehan, lokasi penyimpanan, penanggung jawab, kondisi fisik, dan nomor registrasi aset.

### 7. 📑 Laporan Siap Sidang DKM & Ekspor PDF Eksekutif
* Generator PDF *native* berstandar cetak A4.
* Dilengkapi **Kop Surat Resmi Masjid** (logo, alamat lengkap, kontak sekretariat).
* Dilengkapi **Kolom Pengesahan & Tanda Tangan Digital** (Ketua DKM dan Bendahara).
* Siap diekspor untuk lampiran laporan mingguan Jumat, sidang triwulanan DKM, atau laporan pertanggungjawaban tahunan.

### 8. 🛡️ Audit Trail Lengkap & Integritas Data Anti-Fraud
* Setiap riwayat perubahan atau koreksi transaksi tercatat rapi (*who, when, what was changed*).
* Kebijakan *Reversal / Correction Entry* untuk transaksi yang telah difinalisasi, mencegah penghapusan data secara sepihak tanpa jejak.
* Perlindungan privasi lokal dengan autentikasi PIN / Biometrik.

### 9. ⚡ 100% Offline-First & Privasi Terjamin
* Tidak membutuhkan koneksi internet konstan; bendahara dapat mencatat dan melihat laporan di mana saja dan kapan saja.
* Seluruh data tersimpan secara lokal dan aman di dalam perangkat menggunakan enkripsi SQLite Room.
* Mendukung fitur pencadangan (*backup*) dan pemulihan (*restore*) data terenkripsi.

## 🛠️ Teknologi & Arsitektur

Kanzun dikembangkan dengan standar rekayasa perangkat lunak Android modern untuk menjamin keandalan, skalabilitas, dan performa tinggi:

| Komponen | Teknologi |
| :--- | :--- |
| **Bahasa Pemrograman** | Kotlin 2.0+ |
| **Framework UI** | Jetpack Compose (Material 3) |
| **Pola Arsitektur** | Clean Architecture (Presentation, Domain, Data) + MVI/MVVM |
| **Dependency Injection** | Dagger Hilt |
| **Penyimpanan Lokal** | Room Database (SQLite) dengan Coroutines & Flow |
| **Dokumen Engine** | Android Native Graphics & Canvas PDF Rendering |
| **Asynchronous Engine** | Kotlin Coroutines & Reactive StateFlow |
| **Image & Vector Loader** | Coil (Dukungan SVG & Gambar Terkompresi) |

## 🚀 Panduan Instalasi & Menjalankan Proyek

### Prasyarat Pengembangan
Pastikan lingkungan pengembangan Anda telah memenuhi spesifikasi berikut:
1. **Android Studio**: Versi terbaru (Ladybug / Koala Feature Drop ke atas disarankan).
2. **Java Development Kit (JDK)**: JDK 17 (dikonfigurasi sebagai Gradle JDK).
3. **Android SDK**:
   * Minimum SDK: **API 26** (Android 8.0 Oreo)
   * Compile / Target SDK: **API 35** (Android 15)
4. **Gradle**: Versi 8.11+ (menggunakan Gradle Wrapper bawaan proyek).

### Langkah-Langkah Menjalankan

1. **Kloning Repositori**:
   ```bash
   git clone https://github.com/GHXZY/Kanzun-DKM.git
   cd Kanzun-DKM
   ```

2. **Buka Proyek**:
   * Buka Android Studio.
   * Pilih menu **File** > **Open**, lalu pilih direktori proyek `Kanzun-DKM`.
   * Tunggu proses Gradle Sync hingga selesai mengunduh seluruh dependensi.

3. **Menjalankan Pengujian Otomatis (Unit Test)**:
   ```bash
   ./gradlew testDebugUnitTest
   ```

4. **Kompilasi & Build APK Debug**:
   * Di terminal Android Studio / Bash:
     ```bash
     ./gradlew assembleDebug
     ```
   * Berkas APK hasil kompilasi akan berada di:
     `app/build/outputs/apk/debug/app-debug.apk`

5. **Menjalankan di Perangkat / Emulator**:
   * Hubungkan perangkat fisik Android melalui USB Debugging atau aktifkan Android Emulator.
   * Tekan tombol **Run (Shift + F10)** di Android Studio, atau pasang APK melalui ADB:
     ```bash
     adb install -r app/build/outputs/apk/debug/app-debug.apk
     ```

## 👥 Peran Pengguna (*User Roles*)

Sistem dirancang untuk mendukung pembagian kewenangan yang akuntabel:
* **Bendahara**: Pengelola operasional harian (pencatatan transaksi, rekonsiliasi, penyusunan anggaran, pengelolaan aset, dan penerbitan laporan).
* **Ketua DKM**: Pengawas strategis (peninjauan saldo real-time, evaluasi realisasi RAPBM, persetujuan program target dana, dan penandatanganan laporan resmi).
* **Auditor / Pemeriksa Internal**: Peninjau independen (pemeriksaan mutasi transaksi, rekonsiliasi kas, dan penelusuran audit trail tanpa izin mengubah data).
